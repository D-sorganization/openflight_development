# Working Notes

Scratch space for session logs' summaries, experiment write-ups, and observations that aren't ready for a review doc or an upstream issue.

Conventions:

- One file per topic or session, date-prefixed: `2026-07-30-topic.md`
- Raw session data (JSONL, `.l3dump`, `.pkl`) stays **out of git** (see `.gitignore`) — summarize here, keep raw files in local storage / cloud backup
- Anything that firms up graduates to `project-reviews/` or to an upstream issue/PR on
  [`jewbetcha/openflight`](https://github.com/jewbetcha/openflight). This repo files no
  GitHub issues of its own — see [`backlog/README.md`](../backlog/README.md)
